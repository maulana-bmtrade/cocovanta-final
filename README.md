# COCOVANTA — Coconut-Shell Charcoal Briquettes Export Website

Static, multi-page export website for COCOVANTA, focused exclusively on coconut-shell charcoal briquettes for BBQ and shisha/hookah markets. The site presents buyer information, product formats, indicative specifications, quality-verification approach, export workflow, FAQs, privacy notice, commercial terms and a buyer quotation handoff.

## Publish to GitHub Pages
1. Extract the ZIP. Upload the contents of the `cocovanta-international-main` folder to the repository root (the root should directly contain `index.html`, `CNAME`, `assets/`, and the other HTML pages).
2. In GitHub Pages settings, select the intended publishing branch and `/ (root)`.
3. Keep `CNAME` containing exactly `cocovanta.web.id`.
4. Configure the DNS records shown by GitHub Pages for the custom domain. Do not mix records from different hosting providers.
5. After DNS verification, enable HTTPS and test both `https://cocovanta.web.id/` and `https://www.cocovanta.web.id/` according to the canonical domain configuration.
