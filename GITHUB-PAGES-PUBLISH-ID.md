# Panduan publikasi COCOVANTA

1. Ekstrak ZIP dan buka folder `cocovanta-international-main`.
2. Unggah **isi folder tersebut** ke root repository GitHub, bukan folder induknya. Pastikan `index.html`, `CNAME`, `assets/`, `css/` dan halaman HTML berada langsung di root.
3. Aktifkan GitHub Pages pada branch dan direktori `/ (root)` yang dipilih.
4. Pastikan file `CNAME` berisi `cocovanta.web.id`.
5. Atur DNS sesuai instruksi GitHub Pages untuk custom domain, lalu tunggu verifikasi dan aktifkan HTTPS.
6. Uji halaman Home, Products, Specifications, Contact, Privacy, tautan email, serta tombol WhatsApp dari ponsel dan desktop.

Formulir RFQ hanya menyiapkan pesan WhatsApp. Pembeli harus memeriksa pesan dan menekan Send sendiri. Website statis tidak menyimpan permintaan atau mengirim notifikasi otomatis.
